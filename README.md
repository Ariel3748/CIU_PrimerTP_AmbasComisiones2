# Librería Digital - Tienda de Libros Online

Una aplicación web interactiva desarrollada en **React** que simula la experiencia completa de una tienda de libros. Cuenta con catálogo interactivo, filtros de búsqueda, gestión de stock en tiempo real mediante Context API, sistema de cupones promocionales y validación avanzada de datos de contacto/envío.

---

## Tecnologías Utilizadas

* **React 18** (con Vite)
* **React Router DOM** (Gestión de rutas)
* **React-Bootstrap** (Estilos y diseño responsivo)
* **Context API** (Estado global del carrito y persistencia en LocalStorage)
